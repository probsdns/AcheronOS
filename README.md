AcheronOS

AcheronOS uses a command interface to launch apps and access other built in features and has customisation and privacy features.

AcheronOS includes a first few letters system where instead of typing out full commands you can type the first few letters in the command, if (for example) 2 apps have the same 2 or 3 or more letters such as apple music and app store then you'll have to type more specific letters forming some of the app's name so the system can tell which app ur tryna access without u having to fully type out the name, a minimum of 2 letters is required to launch an app or run a command.

Command "Help" gives you a list of all the available commands and what they do.

Hidden command "?" gives you access so a set of prehidden apps that u can change using commands unhide and hide, for info on how to use them just type help.

Currently only compatible with the z fold 8 ultra but might work with other phones cuz it does use jetpack compose which might be able to resize menus but i cant guarantee it would look good.
