#AcheronOS App Launcher

The App Launcher for AcheronOS which uses a command interface to launch apps and access other built in features and has customisation and privacy features.

AcheronOS's App launcher includes a first few letters system where instead of typing out full commands you can type the first few letters in the command, if (for example) 2 apps have the same 2 or 3 or more letters such as apple music and app store then you'll have to type more specific letters forming some of the app's name so the system can tell which app ur tryna access without u having to fully type out the name, a minimum of 2 letters is required to launch an app or run a command.

Command "Help" gives you a list of all the available commands and what they do.

Hidden command "?" gives you access to happs such as chatgpt, discord, google chat, messages, tiktok and youtube, first few letters system also works here and typing commands such as help will not show the command "?" since the whole point of the folder is to stay hidden. To exit the "?" folder u need to type either "/", "back" or you can use the back button in oneui's navigation bar if available.

Currently only compatible with the z fold 8 ultra but might work with other phones cuz it does use jetpack compose which might be able to resize menus but i cant guarantee it would look good.
